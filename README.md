# Primtal
Slack agent for daily opt-in mental health check-ins and journaling, with crisis-resource routing to a company's therapist. Built for the Valencia AI Tinkerers OpenAI hackathon (Sept 2026).

## Current implementation

The Ambiguous + OpenRouter + CopilotKit demo is being developed in `apps/agent`. It is work in progress; deployment and live integration are pending.
